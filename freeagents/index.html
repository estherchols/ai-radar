How to use themNo setup service, no sign-up

  1. Open the tool's page on GitHub and read its README first. It says what you need and what it costs to run, which is usually nothing.
  2. Download it with the green Code button, or fork it if you want your own copy to change.
  3. Follow the setup steps in the README. Most tools need one or two keys, like a Telegram bot token.
  4. If something breaks, open an issue on GitHub so I can fix it for everyone.
